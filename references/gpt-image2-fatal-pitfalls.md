# gpt-image-2-high 致命坑位速查（2026-08-05）

本文件记录在 gpt-image-2-high（Codex OAuth）上反复验证的失败模式及修正方案。
每日生图 cron 的 prompt 构建阶段应逐条对照审计。

---

## 坑 1：低反差光线 + 浅色主体 = 必糊

**现象**：画面整体偏软/糊，锐度不足，飞书传输后尤其明显。

**触发条件**（满足 2 项即高危）：
- 光线：golden hour backlight / window light / overcast soft light / diffused fill
- 主体颜色：白色、奶油色、浅粉、浅灰等浅色调
- 背景颜色：沙漠、白沙、白墙、白床单、雪地、浅色天空

**典型失败案例**：
- "沙漠高定时装 + 金色逆光 + 奶油色礼服" → 糊（2026-08-05 验证）
- "白蕾丝 + 白床单 + 柔光窗光" → 糊（历史验证）

**修正方案**：
- 换硬光：Rembrandt / split lighting / chiaroscuro / single harsh key
- 换深色背景：黑色火山岩、暗巷、暴风雨天空、深色木墙
- 换撞色主体：深红、墨绿、宝蓝 vs 深色背景
- 或直接切 xAI Grok（锐度天然高于 Codex）

---

## 坑 2：gpt-image-2-high 搞不定黑白纪实人像

**现象**：黑白人像面部塑料感、像 CGI 渲染、皮肤细节丢失。

**触发条件**：
- 黑白（Ilford HP5 / Tri-X / B&W）
- 需要极致面部写实（皱纹、毛孔、毛细血管）
- 纪实/人文风格（Salgado / McCurry B&W）

**典型失败案例**：
- "乌尤尼盐矿工 + Salgado + Ilford HP5 黑白" → 太假（2026-08-05 验证）

**修正方案**：
- 切 xAI Grok（黑白面部细节远好于 Codex）
- 或保留彩色纪实人像 + 后期去饱和
- 或换彩色纪实风格（保留肤色作为真实感锚点）

---

## 坑 3：低反差场景 + 飞书压缩 = 锐度归零

**原理**：飞书对图片有压缩，低反差画面的细节在压缩后消失。

**触发条件**：
- 画面整体影调偏亮/偏灰
- 没有明显的 dark anchor（黑色锚点区域）

**修正方案**：
- 确保画面有 ≥20% 的深黑区域
- 优先硬光 + 深阴影组合
- 避免全画面 mid-tone（中灰调）分布

---

## 修正优先级

生图 prompt 审计时，按此顺序检查：
1. 光线类型 → 柔光？换硬光
2. 色彩对比 → 低反差？换深色背景或撞色
3. 黑白判断 → 黑白人像？切 Grok
4. 暗部锚点 → 没有深黑区域？加投影/暗角/暗背景

核心铁律：**用户偏好高反差 + 深阴影 + 锐利纹理，不是柔美/梦幻/氛围感。**
